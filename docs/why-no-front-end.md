# Why there is no application front end

Weekly requirements work is reading, reviewing and linking records, preparing evidence and producing specifications. The CLI and coding agent do that against a database you own. Read-only HTML views give the review meeting a shared snapshot.

A screen adds rich-text authoring, drag-and-drop hierarchy, visual diagrams, concurrent editing and mobile workflows. This free base does not supply those experiences or offline mobile synchronisation. It stores plain text and evidence references. HTML reports are snapshots, not interactive write screens. Enterprise DNA can build the agreed interface and integrations for the installed version.

ReqView already offers traceability, exports and an open project format. This build is an ownership and customisation option, not a claim that ReqView hides your data or cannot answer a particular question. Hosting and coding-agent usage have their own costs.
